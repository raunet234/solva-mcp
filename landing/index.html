Works with any MCP-compatible agent or IDE.

Claude Code, Cursor, Windsurf, VS Code, or any tool that supports the Model Context Protocol. Configure once — Solva works everywhere.

Works with any MCP client.

Solva is not limited to Claude Code. Any agent or IDE that supports the Model Context Protocol can install Solva and start making autonomous x402 payments on Stellar. Configure once, pay anywhere.

View setup docs →
// Claude Code
claude mcp add solva -- npx tsx /path/to/solva-mcp/src/index.ts

// Cursor / Windsurf / VS Code
{
  "mcpServers": {
    "solva": {
      "command": "npx",
      "args": ["tsx", "/path/to/solva-mcp/src/index.ts"],
      "env": {
        "STELLAR_SECRET_KEY": "S..."
      }
    }
  }
}

// Then just type your task:
"find me latest news about AI payments"
// Solva handles discovery + payment automatically
