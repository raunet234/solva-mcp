Custom Skills

Solva exposes powerful MCP tools that AI agents can call autonomously. Each skill handles a specific part of the discovery and payment workflow.

● Live

solva_discover_and_pay

The core skill. Give it a natural language task and it automatically detects the service category, discovers compliant providers, pays with USDC on Stellar, and returns the result — all in one call.

discoverypaymentx402stellar

Parameters

taskstring
// Usage in Claude Code
solva.discover_and_pay({
  task: "find latest news about AI"
});

// ✓ Category: news
// ✓ Service: XLM News Wire
// ✓ Price: $0.002 USDC
// ✓ Tx: 7c2ef3...

solva_list_service

Register x402-enabled endpoints in the Solva marketplace. Validates health, x402 compliance, and Stellar payment support before adding to the live registry.

marketplaceregistrationvalidation

Parameters

urlstring
categorystring
priceUSDCnumber
// Register a service
solva.list_service({
  url: "https://api.myservice.com",
  category: "search",
  priceUSDC: 0.003
});

solva_check_policy

Evaluate a service against the agent's spending policy without making a payment. Perfect for dry-running tasks and auditing the registry.

policyauditcompliance

Parameters

serviceIdstring
// Dry-run policy check
solva.check_policy({
  serviceId: "weather-skyvault"
});

// ✗ uptime 95.5% < min 97%
// ✗ payments 45 < min 100

solva_browse_registry

Browse all services in the marketplace, optionally filtered by category. Returns pricing, uptime, and compliance status for each service.

registrybrowsediscovery

Parameters

categorystring (optional)
// Browse news services
solva.browse_registry({
  category: "news"
});

// 📰 XLM News Wire
// $0.002 | 99.2% | ✓ PASS
