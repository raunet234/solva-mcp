Tech Stack

The technologies powering Solva MCP.

TypeScript Model Context Protocol Stellar SDK x402 Protocol USDC (Circle) Soroban Node.js 20+ Zod Validation
🔍

Category Detection

Keyword-based mapping from natural language tasks to service categories (news, search, summarize, weather). Extensible via the CATEGORY_KEYWORDS map.

🛡️

Policy Engine

JSON-based rules that filter services by max price, min uptime, min payment history, and daily budget. Agents never spend beyond operator-defined limits.

📦

Service Registry

A JSON marketplace of x402 services with pricing, uptime stats, and payment history. Services are filtered and sorted by the policy engine before selection.

💳

Payment Engine

Sends real USDC micropayments on Stellar testnet using Ed25519 signing. Supports both full x402 negotiation and direct Soroban transfers for mock services.

Quick Integration

Add Solva to any MCP-compatible agent or IDE in seconds.

// Claude Code — one command
claude mcp add solva npx tsx /path/to/solva-mcp/src/index.ts

// Cursor / VS Code / Windsurf — MCP config
{
  "mcpServers": {
    "solva": {
      "command": "npx",
      "args": ["tsx", "/path/to/solva-mcp/src/index.ts"],
      "env": { "STELLAR_SECRET_KEY": "S..." }
    }
  }
}
🔌

Add a Category

Edit CATEGORY_KEYWORDS in helpers.ts and add a new service to registry.json. Solva will automatically route matching tasks.

⚙️

Customize Policy

Edit policy.json to adjust maxPriceUSDC, minUptimePct, minTotalPayments, and dailyBudgetUSDC for your use case.
