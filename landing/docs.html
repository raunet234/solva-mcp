Overview

Solva MCP is a Model Context Protocol server that gives AI agents the ability to discover services, evaluate them against policies, and pay with real USDC micropayments on Stellar — all from a single natural language command.

Built for: Stellar Hacks: Agents Hackathon 2026
Protocol: x402 — HTTP 402 micropayments on Stellar
Network: Stellar Testnet (real on-chain transactions)

How It Works

  1. User types a task in natural language (e.g. "find latest news about AI")
  2. Solva detects the service category from keywords
  3. Queries the registry and filters by the agent's spending policy
  4. Sends a USDC micropayment on Stellar testnet
  5. Returns the service response + verifiable transaction proof

Prerequisites

  • Node.js 20+ — Required runtime
  • Stellar testnet wallet — Funded with XLM and USDC
  • Claude Code (or any MCP-compatible client)

Installation

# Clone the repository
git clone https://github.com/raunet234/solva-mcp.git
cd solva-mcp

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env and add: STELLAR_SECRET_KEY=S...your_key...

Wallet Setup

1. Get Testnet XLM

Visit Stellar Friendbot to fund your wallet with testnet XLM.

2. Get Testnet USDC

Visit Circle Faucet, select Stellar Testnet, and paste your public key.

3. Setup USDC Trustline

npx tsx scripts/setup-trustline.ts
Note: You must establish a USDC trustline before receiving USDC on Stellar. Run the setup script once.

Policy Engine

The policy engine controls how your agent spends money. Edit policy.json:

{
  "maxPriceUSDC": 0.005,    // Max per request
  "minUptimePct": 97.0,     // Min uptime %
  "minTotalPayments": 100,   // Min payment history
  "dailyBudgetUSDC": 2.0,    // Daily spending limit
  "allowExplorer": false      // Show tx links?
}

x402 Protocol

The x402 protocol enables machine-to-machine micropayments using HTTP 402:

  1. Agent sends GET /api/data to a service
  2. Service responds 402 Payment Required with price and address
  3. Agent signs and submits a USDC payment on Stellar
  4. Agent retries the request with payment proof in headers
  5. Service responds 200 OK with data
Key benefits: No API keys needed (payment IS auth), no subscriptions (pay per request), instant settlement (3-5s on Stellar), on-chain proof for every transaction.
